How to use this in Gemini

Do not upload the whole PickPilot repository. It is too large, and Gemini will copy the current layout.

1. Open gemini.google.com in a new chat.
2. If you can, attach one screenshot of the current Games screen. In the message, say it is the existing design and must not be copied.
3. Paste the prompt from PROMPT_BROADCAST.txt and send it. Ask Gemini to create an image.
4. Open a second new chat and paste PROMPT_PICK.txt the same way. One direction per chat. If both are in one chat, Gemini blends them.

Each prompt asks for a single desktop screenshot of the website, filling the frame. If the first image is a poster, a phone, or a slide, reply: "Regenerate as a full-bleed desktop website screenshot. No device frame, no captions, no annotations."

The current design is direction one. These two prompts are the other directions: Broadcast and Pick.
